# What this corpus checks

This is a deterministic regression corpus for three question-engine collection policies. It does not grade a language model, establish engineering truth or measure the usefulness of an investigation.

The source-informed criteria were set before a repaired candidate. Twenty-one cases preceded their first baseline calls. Four E30 cases followed observation of a separate related-record confound and are explicitly marked development. The two source documents are not 25 independent sources. Links and labels do not authenticate an installed function or grant operating authority.

## Repeat the controls

From the repository root:

```sh
python -S scripts/test_question_engine.py
```

The existing test module checks `expected/cases.json` against the original Native inputs and current engine. It preserves the exact selected subjects and meaningful local candidates, rejects unrelated candidate attachment, checks 28 typed source-field literals and keeps three explicit no-anchor controls quiet. False and zero must not be conflated; unknown text and its blank-state classification must not be silently discarded. Candidate fields do not close requests. The selected rules retain three open collection requests for each applicable subject.

For the three full-report cases, the producer command in the main README provides inspectable JSON and Markdown. A successful test is a software result on these authored inputs. It is not an operator review, a plant trial, a safety finding, a savings estimate, whole-catalog adequacy or a measured before/after improvement in engineer time.
