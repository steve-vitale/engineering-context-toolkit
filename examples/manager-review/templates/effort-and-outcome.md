# Measure the job before expanding it

Manual worksheet. No baseline, hours, error rate, rate of pay or saving is prefilled. Choose scope, comparison,
quality criteria and collection window before the trial. Use actual observations and identify estimates.

| Comparable basis | Record |
|---|---|
| Question/assets, source versions/coverage and intended decision | Not recorded. |
| Current manual method and people/familiarity | Not recorded. |
| Trial method and people/familiarity | Not recorded. |
| Predeclared success/stop criteria and recipient | Not recorded. |
| Differences preventing a fair comparison | Unknown; report rather than hide them. |

| Activity | Manual comparison person-hours | Trial person-hours | Observation/source and missing coverage |
|---|---|---|---|
| Find/export/prepare records | Not measured | Not measured | Not recorded |
| Field verification, where needed | Not measured | Not measured | Not recorded |
| Author/model/draft | Not measured | Not measured | Not recorded |
| Engineering/record-owner review | Not measured | Not measured | Not recorded |
| Correct/rework and repeat review | Not measured | Not measured | Not recorded |
| Recipient reconstructs the answer | Not measured | Not measured | Not recorded |
| Accepted receiving-system correction/readback | Not measured | Not measured | Not recorded |
| Subsequent revision and ongoing upkeep | Not measured | Not measured | Not recorded |

Sum all included person-hours separately for each method; retain elapsed delay separately. For a valid matched
comparison, hours difference = manual total − trial total. Do not omit setup, review or correction effort. Missing
activities make the comparison incomplete. A negative result is retained rather than presented as a saving.

Record incorrect/unsupported conclusions, false asset matches, missed affected records, corrections and residual
unknowns using the same definition and denominator for each method. Counts of known errors are not an accuracy
rate unless the reference and eligible population have been independently reviewed.

| Outcome | Record after the actual exercise |
|---|---|
| Recipient can reconstruct evidence and limits | Not observed. |
| Useful decision/action changed, and recipient's reason | Not observed. |
| Actual receiving verification and residual exclusions | Not observed. |
| Next revision accepted and upkeep burden | Not observed. |
| Continue / narrow / change / stop; decision-maker and date | Not decided. |

If estimating cost, use site-supplied labor assumptions and separately include consulting, software, integration
and recurring support. Distinguish released labor capacity from realized cash savings. Downtime, production loss,
failure frequency and avoided-risk benefits need separate evidence and attribution; do not derive them from
linked records, queue colors or an example percentage.
