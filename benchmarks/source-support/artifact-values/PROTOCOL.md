# Frozen artifact-review CLI proof

Synthetic saved controls only, not model runs. Review the exact admitted saved artifact in its declared
historical source scope. Original source/key review, labels and complete raw artifact/value/context bindings
are retained; no source fetch or present-day installed-state inference occurs. A perfect reviewer can score
14/14 while correctly reporting the false artifact contradiction. Keys/reference/control labels are exposed
in this development proof and must stay outside any future genuine inference packet.

Supported profile: bare Native model with meta.source_document/source_sha256, explicit unknowns/assumptions
lists and record/source citations compatible with the existing description interpretation review. This does
not admit arbitrary Native graphs/models or automatically discover all engineering claims. Manual CSV review
remains the engineer route; this adapter is a contributor benchmark for a reviewed frozen value/group scope.
