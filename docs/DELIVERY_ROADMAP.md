# Delivery roadmap: prove a useful plant job

Working priorities, 2026-11-06. The original [PLAN.md](PLAN.md) remains the dated research/showcase plan.
This roadmap prioritizes useful delivery from the existing tools before more catalog breadth.

| Priority | Work | Observable completion |
|---|---|---|
| 1 | Make maintenance reconciliation and drawing recovery easy to start | Runnable examples, own-input steps, defined outputs and a direct contact path. |
| 2 | Preserve a bounded CAD exchange | Saved source and return files, stable identities/attributes, explicit loss report, deliberate wrong controls and a documented editor/version. General proprietary CAD acceptance stays separate. |
| 3 | Qualify photo/scan capture | Attributed public originals, exact preprocessing/OCR records, reviewed field candidates, unreadable/ambiguous values and saved failures. No claim that OCR identifies the installed asset. |
| 4 | Observe one real recipient using the work | Predeclared question and comparison, actual reconstruction/corrections, total effort and a dated useful/change/stop outcome. Use public records if company data is unavailable. |
| 5 | Accept one real receiving-system handoff and its next change | Native readback, identity/evidence/history checks, retry/manual-edit reconciliation and a subsequent accepted revision. |

## Use public resources first

Reuse the public OPEN100/DEXPI sources, the fictional maintenance replacement and attributed photo exercise.
Keep separate source families separate: a public motor photograph is not evidence about the fictional valve.
No model subscription is needed to inspect the saved examples. A better reader can be evaluated in the
[existing slot](PLUG_IN_A_READER.md); building another reader is not a prerequisite to a useful handoff.

For CAD comparisons use the actual target's public documentation and supported exchange profile. Preserve
third-party licenses; do not copy implementation code from an incompatible project. Existing platforms already
provide [diagram parsing and graph contextualization](https://docs.cognite.com/cdf/integration/guides/contextualization/diagram_parsing).
Evaluate buying, partnering or adapting against the scoped engineering job rather than claiming a new category.

[ChemE-as-Code and Process Atlas](https://www.pi-research.org/post/26-11-05-cheme-as-code/) were publicly released
on 2026-11-05 with linked engineering files, external calculation tools and consistency/freshness checks. Its
authors report an agent-created preliminary engineering package and explicitly state that no independent
engineer reviewed that design. Treat it as relevant prior art and a possible source of separately qualified
public examples, not validated plant truth or evidence of an exclusive market gap. Do not copy third-party
code or data without checking their respective licenses. This delivery uses no code from that project.

## Depth gates

The existing backlog already contains the important unrun exercises: N052 (timed human drawing review), N062
(actual recipient usefulness) and N063 (company handoff and subsequent revision). Software receipts do not close
those items. Use [ACCEPTANCE.md](ACCEPTANCE.md) and retain failures as well as passes. Public sources remove the
need for private data in an initial recipient trial; they do not supply a human participant or a company's system.

Defer speculative connectors, more equipment classes, another general ontology, additional 3D showcases and
autonomous write workflows unless a concrete delivery job requires them. Fix current regressions and keep the
[status](STATUS.md), source limitations and [feature evidence](FEATURES.md) current.

The assistant interface is replaceable. Portable source-linked information should remain useful in CAD, a CMMS,
search or an approved copilot. Microsoft supports both indexed and federated external-content routes, each with
its own deployment and authentication requirements ([connector overview](https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/overview-copilot-connector)).
An MCP protocol pass does not establish company Copilot acceptance.
